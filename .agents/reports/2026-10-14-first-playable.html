Two browser clients shared movement and block edits. The farm produced collectible drops, and Convex restored the saved world after a process restart.

Evidence and rendering limits

TypeScript checks, seven simulation tests, and the production build passed. The tests cover replay, spawning, collision, invalid edits, loot, and the starter farm.

Five production frame samples used two clients at 1280 × 800, DPR 1.5. Median frame time across runs was 316.7 ms, with run medians from 300.0 to 316.7 ms. SwiftShader rendered on a Ryzen 9 8945HS machine sampled at 100% CPU load. This misses 60 FPS and cannot establish hardware GPU performance.

The live world tick advanced during every sample. The primary client logged no application errors; GPU ReadPixels warnings remained. One secondary-tab 404 occurred during an earlier build and cleared after navigation.

Architecture, accounts, and next mechanics

Three.js renders the island. PartyServer runs authoritative shared simulation ticks. Convex stores periodic world saves and the last-player save; empty worlds pause. The room cap is eight, but only two clients were tested.

The accepted defaults are fast movement and combat, finite sky islands, private co-op, paused empty worlds, and chibi characters. This slice includes movement, building, one mob, drops, and an introductory quest. Pearl travel, logic circuits, broader progression, and a full story remain future work.

Cloudflare login is required before hosting the room server: run bunx wrangler login in the repository. Clerk needs an application with real keys, and Convex and Vercel need linked cloud projects. Any requested keys must use the private secret-entry tool. No cloud deployment or paid resource was created.

To restart local play later, run bun run dev from this repository. Setup and verification instructions for agents live under .agents/skills.
